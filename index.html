What I'd tell the next intern

Key learnings

Clean data is a prerequisite, not a formality. The duplicate-ID bug in Task 1 would have silently corrupted every downstream join if it had gone unnoticed.

Statistical validation changes recommendations, not just confidence in them. Three "obvious" hypotheses all failed significance testing — which redirected the whole strategy toward behavioral segmentation instead of demographics.

A dashboard only creates value if someone actually opens it. Building it as a zero-install web app removed every point of friction between "built" and "used."

The best insight is often a negative result. "These three things don't matter" was more strategically useful than confirming something everyone already assumed.
